01 / CYBERSECURITY

File Integrity Toolkit

COMPLETED

A Python-based toolkit for verifying file integrity using cryptographic hashing and digital signatures. Explores secure key handling, signing and verification. It addresses the challenge of detecting unauthorised file modifications using SHA-256 hashing and Ed25519 digital signatures, with encrypted private-key storage for secure signing.

Python SHA-256 Ed25519 Cryptography

02 / CRYPTOGRAPHY

Cipher Arms Race

IN PROGRESS

An interactive cryptography experience where Alice encrypts messages, Bob receives them, and Eve attempts to break the encryption. Currently featuring Caesar and Vigenère ciphers with attack demonstrations. It explores the weaknesses of classical encryption by demonstrating how an attacker can analyse encrypted messages through interactive brute-force and cipher attack simulations.

HTML CSS JavaScript Cryptography

03 / AUTOMOTIVE TECHNOLOGY

Automotive Sensor Fusion

COMPLETED

A simulation-based study exploring delayed radar and camera measurements and comparing methods for improving vehicle position estimation. It addresses the challenge of sensor latency by evaluating delayed measurement handling strategies and comparing their impact on vehicle position estimation under different motion conditions.
