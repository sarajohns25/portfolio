# Sara Johns — Personal Portfolio

Hey! I'm Sara, a BE Cybersecurity student who enjoys exploring technology, experimenting with ideas and building things along the way.

This is my personal portfolio, where I've brought together some of the projects I've worked on, things I've learned and a little bit of my creative side.

I wanted this website to feel like more than just a place to list projects. So instead of keeping everything in the usual format, I experimented with a few interactive ideas and gave different sections their own personality.

**Have a look around:**  
https://sarajohns25.isonewho.codes/

## A little about the website

There are a few things I wanted to make differently:

- **The Vault:** A mechanical vault-inspired space where you can unlock and explore my technical projects.
- **Between the Lines:** A virtual poetry book featuring two of my original poems, written from different perspectives. This section is a little more personal to me.
- **The Rotary Telephone:** A vintage-inspired contact section. Pick up the receiver to reveal my contact details.

I had fun experimenting with the interactions, layouts and little details that bring these sections together.

## Projects I've worked on

### 1. File Integrity Toolkit

A Python project exploring ways to check whether files have been modified or tampered with. It uses SHA-256 hashing and Ed25519 digital signatures, along with encrypted private-key storage.

[GitHub Repository](https://github.com/sarajohns25/file-integrity-toolkit)

### 2. Cipher Arms Race

An interactive cryptography project built around Alice, Bob and Eve. It demonstrates classical encryption methods such as Caesar and Vigenère ciphers and explores how an attacker can analyse their weaknesses.

[GitHub Repository](https://github.com/sarajohns25/cipher-arms-race)

### 3. Sensor Fusion with Delayed Measurements

A software simulation focused on what happens when radar and camera measurements arrive late. It explores different ways of handling sensor delays and compares their effect on vehicle position estimation.

[GitHub Repository](https://github.com/sarajohns25/sensor-fusion-delay)
